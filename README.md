# 🧮 ipywidgets Interactive Calculator for Jupyter & Colab

A lightweight, interactive GUI calculator built entirely in Python using **`ipywidgets`**. It allows users to perform basic arithmetic operations directly inside Jupyter Notebooks or Google Colab without needing any external web frameworks or complex GUI installations.

## ✨ Features

* **Interactive Button Grid:** Standard calculator layout with numbers (`0-9`), basic operators (`+`, `-`, `*`, `/`), clear (`C`), and equals (`=`).
* **Zero Web Hosting Required:** Runs completely inside the notebook environment kernel.
* **Responsive Styling:** Clean bordered layout with custom button sizing and typography.
